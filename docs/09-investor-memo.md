# 투자 메모

> 건설·프롭테크 AX는 “AI를 건설에 붙이는 시장”이 아니라, 안전·원가·공기·문서·에너지·PF 리스크라는 기존 비용 항목을 소프트웨어 매출로 전환하는 시장이다.

## 한 줄 Thesis

건설·부동산 산업은 디지털 전환이 늦어서 매력적인 것이 아니라, **비용 누수의 단위가 크고 구매 명분이 이미 예산 항목으로 존재하기 때문에** 매력적이다. AX 기업은 범용 AI 도구가 아니라, 현장과 자산의 업무 데이터를 장악하는 **버티컬 운영 레이어**로 성장할 수 있다.

## 왜 지금인가

| 압력 | 시장에서 생기는 변화 | AX 구매 명분 |
| --- | --- | --- |
| 중대재해처벌법과 안전 책임 | 안전이 현장 관리 문제가 아니라 경영진 리스크가 됨 | AI 안전 모니터링, 자동 리포트, 위험 행동 감지 |
| 인력 고령화·숙련공 부족 | 견적, 공무, 안전, 현장 기록의 수작업 병목 심화 | 도면 takeoff, 계약/RFI RAG, 일보 자동화 |
| 공사비 상승과 PF 경색 | 원가·일정·사업성 오차를 흡수할 여유 감소 | 예측 견적, 공정 리스크, PF/사업성 분석 |
| BIM·스마트건설 정책 | 공공·대형 프로젝트 중심으로 데이터화 압력 증가 | BIM 품질 검토, 도면·공정·현장 데이터 연결 |
| 에너지·O&M 비용 | 자산 가격 상승보다 NOI 개선이 중요해짐 | AI HVAC, 예지보전, 운영비 절감 |

## 첫 진입점

가장 좋은 첫 제품은 “전사 AX 플랫폼”이 아니다. 초기 제품은 고객의 기존 업무 예산과 직접 연결되어야 한다.

| 우선순위 | Wedge | 구매자 | 왜 지금 팔리는가 | 확장 경로 |
| --- | --- | --- | --- | --- |
| 1 | AI 안전 모니터링 | 안전보건실, 현장소장, 경영진 | 규제·형사 책임·작업중지 리스크가 예산을 연다 | 안전 리포트 → 보험/위험 데이터 → 현장 OS |
| 2 | 계약/RFI/클레임 문서 RAG | 공무, 법무, PM | 문서가 이미 있고 행동 변화가 작다 | 공무 자동화 → 변경계약/클레임 리스크 관리 |
| 3 | 도면 기반 물량산출/견적 | 견적, 구매, 공종별 실무팀 | 입찰 처리량과 인건비 절감이 바로 보인다 | 견적 DB → 자재 조달 → 원가 예측 |
| 4 | 재건축·시행 행정 자동화 | 조합, 시행사, PM | 동의서·총회·민원·문서 비용이 크다 | 조합/시행 데이터 → 사업성·PF 분석 |
| 5 | CRE/PF 리스크 분석 | 시행사, 금융권, 운용사 | PF 구조조정과 담보가치 검증 니즈 증가 | AVM → 심사 자동화 → 투자 의사결정 레이어 |

## 왜 경쟁이 있어도 기회가 남는가

글로벌 플랫폼은 크고 강하지만 한국의 공무 문서, 하도급 관행, 세금·증빙, 중대재해 대응, 공공 발주 관행, 한국어 계약/RFI/회의록 처리까지 깊게 들어가기 어렵다. 국내 대형사는 자체 AI를 만들 수 있지만, 중견·전문건설·시행·PM/FM 영역은 외부 솔루션을 필요로 한다. 이 사이에 **한국형 업무·문서·규제에 특화된 AX 레이어**의 빈틈이 있다.

## 투자자가 베팅하는 지점

투자자는 “건설 AI 기능”에 베팅하는 것이 아니라 아래의 전환에 베팅한다.

```text
특정 업무 자동화
→ 데이터 접근권 확보
→ 반복 가능한 PoC/패키지화
→ 현장·자산 단위 확장
→ 도면·문서·사진·일정·비용·O&M 데이터 통합
→ 산업 운영/의사결정 레이어
```

## 12개월 실행 가설

| 기간 | 목표 | 산출물 |
| --- | --- | --- |
| 0~90일 | 안전·문서·견적 중 하나의 wedge 검증 | 유료 PoC 2~3건, baseline KPI, 고객 인터뷰 |
| 90~180일 | 같은 고객군 내 반복 판매 구조 검증 | 표준 데이터 체크리스트, 가격표, PoC 리포트 템플릿 |
| 180~365일 | adjacent workflow 확장 | 안전+일보, RFI+계약, 견적+구매처럼 연결 제품 출시 |
| 365일 이후 | 데이터 레이어화 | 고객별 현장·자산 데이터 모델, 대시보드, 예측/추천 기능 |

## 결론

이 시장은 “AI를 써보자”가 아니라 “더 이상 기존 방식으로는 원가·안전·공기·금융 리스크를 감당하기 어렵다”에서 열린다. 가장 좋은 투자 대상은 거대한 비전을 말하는 팀이 아니라, 좁은 업무에서 돈을 아끼게 만들고 그 과정에서 산업 데이터를 장악하는 팀이다.
