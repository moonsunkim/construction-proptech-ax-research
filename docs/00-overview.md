# 개요

건설·프롭테크 AX 리서치 문서 허브입니다. 이 위키는 단순 사례 모음이 아니라, **왜 지금 이 분야에 진입하고 검토할 만한지**를 시장·운영·데이터 관점에서 연결한 구조화된 리서치입니다.

## 읽는 순서

| 순서 | 문서 | 목적 |
| --- | --- | --- |
| 1 | 종합 분석 | 전체 시장 기회, 진입 논리, GTM, 가격, PoC, 리스크까지 통합 이해 |
| 2 | 보강 리서치 데이터 | Wedge, 예산 소유자, 한국 타이밍, 경쟁 빈틈, 운영 레이어 논리 확인 |
| 3 | 기초 리서치 데이터 | 글로벌/국내/스타트업/ROI/워크플로우/프롭테크/GTM/투자 지도 원자료 확인 |
