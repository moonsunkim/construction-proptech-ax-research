# 개요

건설·프롭테크 AX 리서치 문서 허브입니다. 이 위키는 단순 사례 모음이 아니라, **왜 지금 이 분야에 진입하고 투자할 만한지**를 투자자 관점에서 연결한 구조화된 리서치입니다.

## 읽는 순서

| 순서 | 문서 | 목적 |
| --- | --- | --- |
| 1 | 투자 메모 | 5분 안에 투자 Thesis, 첫 wedge, 왜 지금인지 파악 |
| 2 | 종합 | 전체 시장 기회, GTM, 가격, PoC, 리스크까지 통합 이해 |
| 3 | 추가 분석 | Wedge, 예산 소유자, 한국 타이밍, 경쟁 빈틈, 운영 레이어 논리 확인 |
| 4 | 리서치 데이터 | 글로벌/국내/스타트업/ROI/워크플로우/프롭테크/GTM/투자 지도 원자료 확인 |

## 문서 구조

### 핵심 문서

| 문서 | 역할 |
| --- | --- |
| 투자 메모 | 외부 투자자에게 바로 보여줄 수 있는 one-page thesis |
| 종합 | 전체 리서치를 하나의 시장 진입·투자 논리로 재구성한 보고서 |

### 추가 분석

| 문서 | 핵심 질문 |
| --- | --- |
| Wedge Ranking | 한국 시장에서 가장 먼저 매출이 되는 AX 진입점은 무엇인가 |
| Budget Owner Map | 누가 어떤 예산으로 AX를 구매하는가 |
| Korea Why Now | 왜 한국 건설·프롭테크 시장에서 지금 AX 도입 압력이 커졌는가 |
| Competitive White Space | 글로벌/국내 플레이어가 놓치고 있는 빈틈은 어디인가 |
| AX Operating Layer | point solution이 어떻게 산업 운영 레이어로 확장되는가 |

### 리서치 데이터

| 문서 | 역할 |
| --- | --- |
| 글로벌 대기업·엔터프라이즈 사례 | 해외 대형 건설사·부동산 기업의 AI/AX 도입 사례와 ROI 근거 |
| 국내 건설사·프롭테크 사례 | 한국 건설사·프롭테크 기업의 스마트건설/AI 적용 사례 |
| 중소기업·스타트업·프로젝트 단위 사례 | 초기 기업·개별 프로젝트 단위의 적용처와 실증 사례 |
| ROI Proof Bank — 상세 사례 | 투자자 피칭에 활용 가능한 정량 성과·ROI 근거 모음 |
| 건설 워크플로우 AX 적용처 지도 | 건설 가치사슬별 AX 기회, 마찰도, 우선순위 지도 |
| 프롭테크 Money Map | 프롭테크 밸류체인과 실제 예산·수익 풀 분석 |
| AX 포지셔닝·가격·GTM | 한국 시장 진입, 가격 전략, GTM 설계 |
| 투자 Thesis·시장 지도 | 투자 테제, 파트너 전략, 90/180/365일 로드맵 |

## 핵심 연결 구조

```text
글로벌 ROI 사례
→ 한국 도입 압력
→ 예산 소유자와 구매 트리거
→ 첫 wedge 선정
→ 경쟁 white space
→ 데이터/운영 레이어 확장
→ 투자 가능한 버티컬 AX 사업
```
