# 개요

건설·프롭테크 AX 리서치 문서 허브입니다. 이 위키는 단순 사례 모음이 아니라, **우리가 이 사업에 뛰어들 만한 이유가 있는지**를 시장·제품·포지셔닝·운영 데이터 관점에서 검토하기 위한 구조화된 리서치입니다.

## 읽는 순서

| 순서 | 문서 | 목적 |
| --- | --- | --- |
| 1 | 종합 분석 | 전체 시장 기회, 제품 진입점, 포지셔닝, GTM, 리스크를 직관적으로 이해 |
| 2 | 리서치 데이터 | 13개 리서치 원자료를 같은 뎁스에서 확인 |
| 3 | 필요한 주제별 상세 확인 | 웨지, 예산 주체, 한국 타이밍, 경쟁 공백, 운영 레이어, 글로벌/국내 사례, ROI, GTM 근거 확인 |

## 문서 구조

### 핵심 문서

| 문서 | 역할 |
| --- | --- |
| 종합 분석 | 리서치 원자료를 바탕으로 “사업에 뛰어들 만한 이유가 있는가”를 제품·시장·포지셔닝 관점에서 재구성한 보고서 |

### 리서치 데이터

| 문서 | 역할 |
| --- | --- |
| 웨지 랭킹 | 한국 시장에서 가장 먼저 검증 가능한 AX 진입점 분석 |
| 예산 주체와 구매 여정 | 누가 어떤 예산으로 AX를 구매하는지 분석 |
| 한국, 왜 지금인가 | 한국 건설·프롭테크 시장에서 지금 AX 도입 압력이 커진 이유 |
| 경쟁 공백 영역 | 글로벌/국내 플레이어가 놓치고 있는 현지화 빈틈 분석 |
| AX 운영 레이어 논리 | 포인트 솔루션이 산업 운영 레이어로 확장되는 경로 |
| 글로벌 대기업·엔터프라이즈 사례 | 해외 대형 건설사·부동산 기업의 AI/AX 도입 사례와 ROI 근거 |
| 국내 건설사·프롭테크 사례 | 한국 건설사·프롭테크 기업의 스마트건설/AI 적용 사례 |
| 중소기업·스타트업·프로젝트 단위 사례 | 초기 기업·개별 프로젝트 단위의 적용처와 실증 사례 |
| ROI Proof Bank — 상세 사례 | 정량 성과·ROI 근거 모음 |
| 건설 워크플로우 AX 적용처 지도 | 건설 가치사슬별 AX 기회, 마찰도, 우선순위 지도 |
| 프롭테크 Money Map | 프롭테크 밸류체인과 실제 예산·수익 풀 분석 |
| AX 포지셔닝·가격·GTM | 한국 시장 진입, 가격 전략, GTM 설계 |
| 시장 진입 논리·시장 지도 | 시장 테제, 파트너 전략, 90/180/365일 로드맵 |
